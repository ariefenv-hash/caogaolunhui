# 草稿轮回 · Draft Loop

一个玩法新奇的火柴人解谜平台小游戏 —— **死亡不是失败，是草稿**。

你是方格草稿纸上的火柴人。每次倒下（或按 R 主动结束本轮），这一轮的奔跑都会留下一份
**「旧稿」**：一支彩铅火柴人原样重演你的一生；它消散后化作**永久留在纸上的划痕**，
替你踩住机关踏板。与无数个"过去的自己"合作，用一张张草稿铺开通往出口的路。

## 玩法核心

1. **轮回回声**：每轮操作被逐帧录制，重生后旧稿会同步重放；遗骸会永久压住踏板。
2. **死亡即策略**：故意"牺牲"在踏板上，让旧稿替你开门；死亡次数就是你的资源。
3. **节拍与协作**：锯齿只伤活人、激光有节拍、同组踏板需同时踩住——最后两关需要 3～4 份旧稿合奏。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或 ← / → | 移动 |
| W / ↑ / 空格 | 跳跃（按住跳得更高） |
| R | 牺牲本轮（立刻留下一份旧稿并重生） |
| C | 重画本关（清空所有旧稿重来） |
| Esc | 暂停 |
| M | 音效开关 |

**手机 / 触屏**：触屏设备会自动显示虚拟按键（◀ ▶ 移动、「跳」跳跃、R 牺牲、‖ 暂停），
支持多点触控，左手移动右手起跳。

墨滴是每关的可收集要素（死亡不丢失，重画才重置），用于全收集挑战。

## 运行

```bash
npm install
npm run dev        # 开发：http://localhost:5173
```

## 构建与试玩

```bash
npm run build      # 产物在 dist/（相对路径，可部署任意静态目录）
npx serve dist     # 或 python3 -m http.server 8000 -d dist
```

> 游戏需要键盘或触屏，电脑与手机浏览器均可游玩。进度保存在浏览器 localStorage 中。

## 技术栈与结构

React 18 + TypeScript + Vite 5；游戏本体为 Canvas 2D 手写引擎
（60Hz 固定步长物理、逐帧位置录制与确定性重放、程序化火柴人骨骼动画、
WebAudio 合成音效、离屏预渲染方格纸背景、Pointer Events 多点触控虚拟按键），零第三方游戏库依赖。

```
src/
├── App.tsx                 # 屏幕路由 + 进度
├── progress.ts             # localStorage 存档
├── components/             # 菜单 / 选关 / 游戏 HUD 与浮层
└── game/
    ├── engine.ts           # 游戏循环、物理、录制重放、机关逻辑
    ├── levels.ts           # 8 个手工设计的关卡
    ├── stickman.ts         # 程序化火柴人（跑/跳/落/倒下姿势）
    ├── render.ts           # 方格纸与机关渲染
    ├── particles.ts        # 墨水飞溅 / 灰尘
    ├── audio.ts            # WebAudio 音效合成
    ├── input.ts            # 键盘输入（含土狼时间、跳跃缓冲）
    └── constants.ts        # 物理与配色
```

## 通关指引（剧透警告）

<summary>点开查看每关思路</summary>

1. **第一笔**：跳跃教学，直奔漩涡。
2. **舍得**：站上左侧踏板按 R，旧稿替你踩住；跳过尖刺深渊穿门。
3. **两全**：先死在地面踏板 A，再爬上台子死在踏板 B，最后一跑穿两门。
4. **锯之舞**：躲两只巡逻锯齿爬上右侧平台牺牲；旧稿不怕锯，你的最后一跑才怕。
5. **红与蓝**：同组双踏板——先死左边一份，穿过门再死右边一份。
6. **激光节拍**：先向左穿第一条激光死在踏板上；再向右数拍子穿三条激光。
7. **弹簧与深渊**：弹簧上云端台子留旧稿；然后走下方岛链到开门的彼岸。
8. **百稿成诗**：蓝 A1 → 蓝 A2 → 弹簧上云端死在橙踏板 → 最后一跑四稿合奏。
9. **云梯旧影**（大师课一）：弹簧上云端留蓝稿；翻锯齿跳尖刺穿蓝门，上高台留橙稿；最后一段计时穿激光。
10. **四稿终章**（大师课二）：云端蓝稿 → 锯齿后雷区蓝稿 → 跳台上孤台橙稿 → 末稿穿过双门与激光走廊收官。
